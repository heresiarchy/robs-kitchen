# Kitchen Implementation Plan
> **For agentic workers:** Execute inline using superpowers:executing-plans.
**Goal:** Ship the approved private kitchen app and its ChatGPT tools.
**Architecture:** Shared domain calculations, authenticated service, D1 records and R2 uploads. Responsive React app and MCP call the same service.
**Tech Stack:** Vinext, React, TypeScript, Cloudflare D1/R2.
**Spec:** docs/superpowers/specs/2026-11-06-kitchen-design.md

## Global Constraints
Private owner access; metric quantities; durable shared data; no fabricated inventory; review imports before saving; unknown dates stay unknown.

## Review Focus
- Compatible quantities subtract once across combined recipe demand.
- Expired use-by food never counts as usable stock.
- Stale saves and repeated operations cannot lose or duplicate records.
- Every data and attachment read is scoped to authenticated identity.
- Uploaded or fetched untrusted content stays inert and bounded.
