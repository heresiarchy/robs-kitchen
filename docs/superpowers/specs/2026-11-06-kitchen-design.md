# Rob's Kitchen
Approved in conversation on 6 November 2026. Private mobile app plus authenticated Site MCP, using shared D1 records and R2 uploads. Recipe originals and personal adjustments; fridge/freezer/pantry batches with quantity and explicit date type; shopping lists scaled from multiple recipes, merged and reduced by compatible in-stock quantities; purchased items reviewed before stocking. Dashboard shows use-soon food and recipe matches. No invented inventory or recipe seed data.

Imports: recipe URLs with public recipe structured data; pasted recipes/receipts/Ocado delivery text; image and EML uploads in a review inbox. The MCP exposes attachments so ChatGPT can extract and stage accurate structured records, then approve. Review is the default. Unknown dates remain unknown. Native Sites app eligibility discovery is unavailable, so direct Gmail/Ocado account sync must not be implied. ChatGPT can use its connected Gmail/browser and the kitchen MCP together. No separate AI API key is required for that assisted path.

One cloud app is the only suitable approach: browser-only storage would not share records with MCP or other devices. Use Vinext starter, D1, R2, Sites identity and MCP capability. All records scoped by trusted authenticated user. Metric units only. Distinguish use-by and best-before, exclude expired use-by stock from automatic subtraction. Keep uncertain units separate. All mutations use unique operation identifiers; revision conflicts reject stale saves.
